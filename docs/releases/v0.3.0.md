# Pixel Companion v0.3.0

## 한국어

### 기본 캐릭터와 동작 이미지 개편

- 기본 고양이를 네 발로 낮게 엎드려 걷는 형태로 다시 그렸습니다.
- 뒷모습과 `걷기 1`, `걷기 2`, `걷기 3`을 같은 스타일의 개별 이미지로 제공합니다.
- 왼발·오른발 같은 방향성 이름을 없애 캐릭터 제작자가 원하는 순서로 프레임을 구성하기 쉽게 바꿨습니다.
- 밥 먹기 1·2와 잠자기 1·2 이미지를 추가하고 실제 상호작용 애니메이션에 연결했습니다.
- 기존 `WalkLeft`, `WalkRight`, `WalkMiddle` 사용자 데이터는 각각 새 걷기 1·2·3 슬롯으로 호환됩니다.

### 창 위에서도 조용히 함께하기

- 일반 프로그램 창의 위쪽 가장자리를 캐릭터가 머물 수 있는 지면으로 인식합니다.
- 창이 움직이거나 크기가 달라지면 캐릭터도 자리를 맞춰 따라갑니다.
- 창이 최소화되거나 닫히면 아래쪽의 안전한 지면으로 내려온 뒤 평소 행동으로 돌아갑니다.
- 전체 화면 창, 팝업, 도구 창, Pixel Companion 자체 창은 지면으로 사용하지 않습니다.
- 대상 프로그램 창을 이동하거나 크기를 바꾸는 동작은 하지 않습니다.

### 이동과 복구

- `바탕 화면에서만`, `프로그램 창 위에서만`, `둘 다 사용` 중에서 이동 방식을 고를 수 있습니다.
- 창 지면으로 사용하고 싶지 않은 프로그램은 프로세스 이름으로 제외할 수 있습니다.
- 반투명 편집 화면에서 여러 이동 영역을 그리고, 옮기고, 크기를 바꾸고, 이름을 붙일 수 있습니다.
- 모니터 연결·해제, 해상도, 작업 영역, DPI 배율이 달라지면 가장 가까운 유효 위치로 복구합니다.

### 방해하지 않는 조작

- 클릭 통과 모드를 트레이 메뉴 또는 `Ctrl+Alt+P`로 언제든 해제할 수 있습니다.
- 전체 화면 프로그램이 실행 중일 때 캐릭터를 숨기거나 화면 가장자리에서 기다리게 할 수 있습니다.
- 방해 금지 모드를 켜면 말풍선을 닫고 화면 가장자리에서 조용히 기다립니다.
- 트레이 메뉴에서 표시, 숨기기, 일시정지, 이동 방식, 영역 편집, 클릭 통과, 방해 금지, 자동 시작을 조절할 수 있습니다.

### 호환성과 성능

- v0.2.1 설정과 사용자 캐릭터 이미지를 그대로 불러옵니다.
- 새 설정이 없는 이전 데이터에는 안전한 기본값을 적용합니다.
- 걷지 않을 때 상태 확인 주기를 낮추고, 숨김·일시정지 상태에서는 렌더링 작업을 줄였습니다.
- 한국어 리소스 문장을 다시 다듬고 새 메뉴와 이동 영역 편집 화면을 영어·한국어로 제공합니다.

## English

### Redrawn character actions

- Redraws the default cat with a lower four-paw walking silhouette.
- Replaces directional left/right labels with neutral Walk 1, Walk 2, and Walk 3 slots.
- Adds matching back, two-frame eating, and two-frame sleeping artwork.
- Connects the eating and sleeping frames to the corresponding runtime interactions.
- Keeps legacy WalkLeft, WalkRight, and WalkMiddle profile keys compatible.

### Window-top surfaces

- Eligible program-window top edges can act as read-only walking surfaces.
- The pet follows a window while it moves or resizes and recovers safely when the window is minimized or closed.
- Full-screen windows, popups, tool windows, and Pixel Companion's own windows are excluded.
- Pixel Companion never moves, resizes, minimizes, or otherwise controls a target application window.

### Movement and recovery

- Choose desktop-only, program-windows-only, or combined movement.
- Exclude applications by process name.
- Draw, move, resize, name, and delete multiple regions in a translucent overlay editor.
- Recover after monitor hot-plug, resolution, work-area, and DPI changes.

### Non-disruptive controls

- Recover from click-through through the tray icon or `Ctrl+Alt+P`.
- Hide during full-screen activity or wait quietly at the screen edge.
- Control visibility, pause, movement surfaces, regions, click-through, do-not-disturb, and startup behavior from the tray.

### Compatibility and performance

- Preserve v0.2.1 settings and user character images.
- Apply safe defaults for all new settings.
- Reduce polling and rendering cadence while idle, paused, or hidden.
- Keep all new menus and the movement-region editor available in English and Korean.
