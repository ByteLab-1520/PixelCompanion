# Pixel Companion v0.2.1

캐릭터 이미지 설정 화면의 버튼 정렬을 바로잡고, 프로젝트를 처음 보는 분도 주요 기능을 빠르게 이해할 수 있도록 README 미디어를 보강한 패치 릴리즈입니다.

## 주요 변경 사항

- 각 이미지 카드의 `선택`과 `제거` 버튼을 같은 폭과 높이로 통일했습니다.
- 버튼을 세로로 배치해 한국어·영어 문구가 서로 겹치지 않도록 했습니다.
- 실제 고급 설정 화면 스크린샷을 README에 추가했습니다.
- 기본 캐릭터가 바탕화면을 걷는 짧은 GIF와 v0.2.1 대표 이미지를 추가했습니다.
- Windows 설치, 실행 파일 버전 확인, 제거 검사를 v0.2.1 기준으로 수행합니다.

## 설치 전 확인

이번 설치 파일도 아직 Windows 코드 서명이 없습니다. 공식 GitHub Release에서 내려받고, 함께 제공되는 `PixelCompanion-Installer.exe.sha256`과 체크섬을 비교해 주세요. 서명되지 않은 릴리즈는 앱이 자동으로 설치하지 않고 공식 Release 페이지를 엽니다.

---

This patch release fixes the character-image control layout and improves the README showcase for new visitors.

- Uses equal-width vertical Choose and Remove buttons in every image card.
- Prevents bilingual labels from overlapping neighboring controls.
- Adds a real advanced-settings screenshot, a walking GIF, and a v0.2.1 hero image.
- Re-runs Windows install, executable-version, and uninstall validation for v0.2.1.

The Windows installer is still unsigned. Download it only from the official GitHub Release and verify it with the attached SHA-256 file. Unsigned releases open the official Release page instead of installing automatically.
