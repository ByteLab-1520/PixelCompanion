# Pixel Companion v0.2.0

Pixel Companion을 내 이미지로 꾸미고, 앞으로의 업데이트를 더 안전하게 확인할 수 있도록 다듬은 버전입니다.

## 주요 변경 사항

- 고급 설정에서 PNG, JPG, JPEG, GIF 이미지를 드래그 앤 드롭으로 등록할 수 있습니다.
- 기본, 뒷모습, 걷기 1(왼발), 걷기 2(오른발), 걷기 3(중간) 슬롯을 지원합니다.
- 걷기 이미지가 일부 비어 있어도 기본 이미지로 자연스럽게 대체합니다.
- 하루에 한 번 GitHub Release에서 새 버전을 확인합니다.
- 서명된 업데이트만 앱 안에서 자동 설치하도록 검증 절차를 추가했습니다.
- 설치 파일의 실제 설치, 실행 파일 버전 확인, 제거까지 자동으로 검사합니다.
- 한국어 README를 더 자연스럽게 다듬고 버전별 로드맵을 추가했습니다.

## 설치 전 꼭 확인해 주세요

이번 v0.2.0 설치 파일에는 아직 Windows 코드 서명이 없습니다. Windows SmartScreen에서 ‘알 수 없는 게시자’ 경고가 나타날 수 있습니다.

1. 이 GitHub Release에서 `PixelCompanion-Installer.exe`를 내려받습니다.
2. 함께 제공되는 `PixelCompanion-Installer.exe.sha256`과 파일의 SHA-256을 비교합니다.
3. 출처와 체크섬이 일치할 때만 설치를 진행합니다.

서명이 없는 동안에는 Pixel Companion이 새 버전을 발견해도 자동으로 설치하지 않고, 공식 GitHub Release 페이지를 엽니다. 코드 서명은 프로젝트가 더 많은 공개 사용 기록과 신뢰를 쌓은 뒤 다시 추진할 예정입니다.

---

This release makes custom character setup easier and lays a safer foundation for future updates.

- Drag and drop PNG, JPG, JPEG, or GIF files into dedicated character image slots.
- Configure default, back, left-step, right-step, and middle-step images.
- Missing walking frames fall back safely to the default image.
- Check GitHub Releases daily for new versions.
- Permit in-app automatic installation only for releases marked as signed.
- Smoke-test installation, executable versions, and uninstallation.

The v0.2.0 installer is **not code-signed**. Download it only from this official GitHub Release and verify its SHA-256 checksum. Until signed releases are available, the app opens the official Release page instead of automatically installing an unsigned update.
