# Pixel Companion v0.5.3 UI and Landing Hotfix

This hotfix repairs the Advanced Settings layout and makes Yaroro's falling sequence visually stable.

## Advanced Settings

- Wraps long bilingual labels inside their fixed label column.
- Adds spacing between labels and controls so text no longer overlaps the excluded-app input.
- Keeps the existing responsive scroll layout and fixed Save footer.

## Falling and landing

- Introduces an exclusive landing state shared by movement and animation updates.
- Prevents idle and walking animation ticks from replacing the dedicated falling frame.
- Prevents window-surface refresh from repositioning Yaroro during an active fall.
- Keeps the X-eyed stunned landing visible for 2.5 seconds instead of 0.9 seconds.
- Cancels the previous landing operation immediately when Yaroro is grabbed again.
- Allows only the newest landing operation to restore the normal frame.

## Full-screen default migration

- Moves settings schema 2 to schema 3.
- Migrates the previously saved `Hide` default to `WaitAtEdge` once.
- Keeps `WaitAtEdge` as the default for new settings and allows the user to change it afterward.

## Compatibility

- Existing character images, dialogues, care state, timers, movement regions, and excluded-process settings remain readable.
- Standard and Yaroro editions remain separate products with separate user-data directories.
