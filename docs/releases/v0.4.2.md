# Pixel Companion v0.4.2 Hot Fix

This patch fixes the unresponsive in-app dialogue editor reported in the `for Yaroro` test edition.

## Changes

- Removed the list-selection feedback loop that blocked the UI thread while dialogue values were loaded or edited.
- Kept the selected dialogue item stable while its text, probability, minimum affection, and cooldown are changed.
- Verified editor opening, line selection, text input, and language switching with automated Windows UI interaction.
- The Yaroro installer now detects and silently uninstalls the Standard Pixel Companion application before installation.
- Standard user data is preserved, so installing Yaroro does not erase existing settings or character data.
- Added a dedicated front-facing pixel portrait icon for the Yaroro executables, tray, and installer.
- Changed Yaroro's Korean default greeting to `안녕? 야로로대장이야`; only the exact untouched legacy greeting is migrated.
