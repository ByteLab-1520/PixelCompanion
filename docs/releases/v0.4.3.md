# Pixel Companion v0.4.3 UI & Drag Hot Fix

작은 화면과 높은 Windows 디스플레이 배율에서 대사 편집기 하단이 겹치던 문제와, 프로그램 창 위의 캐릭터를 드래그해 내려놓을 수 없던 문제를 수정한 핫픽스입니다.

## 수정 사항

- 대사 편집기의 오른쪽 입력 항목에 세로 스크롤을 추가했습니다.
- 미리보기, 저장, 닫기 버튼이 편집 항목과 겹치지 않고 하단에 고정됩니다.
- 창 위에서 드래그하는 동안 창 발판 위치 추적을 일시적으로 중지합니다.
- 마우스를 놓으면 창과 바탕 화면 정보를 새로 확인한 뒤 가장 가까운 유효 발판에 착지합니다.
- 드래그 중 발판 동기화가 다시 개입하지 않도록 회귀 테스트를 추가했습니다.

사용자 설정, 캐릭터 이미지와 대사 데이터 형식은 v0.4.2와 호환됩니다.
