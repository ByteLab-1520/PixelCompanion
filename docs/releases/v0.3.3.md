# Pixel Companion v0.3.3 for Yaroro Hot Fix

This patch corrects the walking direction of the bundled Yaroro character.

## Fixed

- Yaroro no longer appears to walk backward.
- The bundled Yaroro frames are now treated as left-facing source artwork.
- Yaroro keeps the original frame while moving left and flips horizontally only while moving right.
- User-supplied character images retain the existing right-facing convention for compatibility.
- Frame fallback continues to distinguish bundled Yaroro artwork from user images.

## Validation

- Adds regression tests for left- and right-facing source artwork moving in both directions.
- Runs the full core test suite on Windows and macOS.
- Builds and smoke-tests the Windows installer before publishing.

## Windows download

Download `PixelCompanion-Installer.exe` from this Release. A matching `PixelCompanion-Installer.exe.sha256` file is included.

The installer is currently unsigned. Windows may show an unknown-publisher warning; verify that the installer came from this repository and compare its SHA-256 checksum before running it.

The Yaroro character assets remain separate from the repository's MIT software license. Refer to `assets/characters/Yaroro/ASSET.md` before reusing or redistributing them.
