# Pixel Companion v0.4.4 Falling Grab Hot Fix

This patch makes repeated dragging safe and simplifies Yaroro's default Korean greeting.

## Changes

- Grabbing the companion during a fall immediately invalidates the previous landing operation.
- Only the newest release can move the character during a fall or attach it to a window or desktop surface.
- Yaroro's default Korean click dialogue now contains only `안녕? 야로로대장이야`.
- Existing untouched stock greetings are migrated, while user-edited and user-added lines are preserved.
- The unsaved-changes confirmation remains above the dialogue editor, activates itself, and puts initial focus on Cancel.
- Advanced Settings previews all bundled Yaroro or Standard character images whenever a custom slot is empty.
- Removing a custom image now visibly returns that slot to its bundled fallback.
- Stray white fragments at the right edge of Yaroro's second eating frame and first sleeping frame were removed without changing the character artwork.
- The Korean README now introduces Yaroro first and uses a fresh capture of the current character settings screen.

## Verification

- Core regression tests cover current, outdated, and interrupted landing operations.
- Dialogue migration tests verify the single default greeting and preservation of custom dialogue.
- Standard and Yaroro builds and tests complete successfully.
