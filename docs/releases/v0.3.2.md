# Pixel Companion v0.3.2 for Yaroro

This special Windows release bundles Yaroro as the default Pixel Companion while retaining the v0.3.0 window-surface, movement-region, tray, click-through, do-not-disturb, and compatibility improvements.

## Yaroro character set

- Adds a consistent 418×418 transparent character set.
- Includes a neutral front pose and a genuine rear view.
- Includes Walk 1, Walk 2, and Walk 3 sequence frames.
- Includes two human mealtime frames with rice, side dishes, and chopsticks.
- Does not depict pet food, kibble, or a feeding bowl.
- Includes two calm sleeping frames with a pillow and breathing variation.
- Keeps custom images selected in Character Settings as the highest-priority character artwork.

## Packaging and compatibility

- Updates application, executable, installer, and release metadata to `0.3.2`.
- Bundles the Yaroro character manifest and animation catalog in the Config application.
- Keeps existing v0.2.x and v0.3.0 user settings and custom character slots compatible.
- Validates required character animations and all referenced frame files.

## Windows download

Download `PixelCompanion-Installer.exe` from this Release. The workflow builds the installer, performs a silent install and uninstall smoke test, and publishes a matching `PixelCompanion-Installer.exe.sha256` file.

The installer is currently unsigned. Windows may show an unknown-publisher warning; verify that the file came from this repository and compare its SHA-256 checksum before running it.
