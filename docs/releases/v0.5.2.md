# Pixel Companion v0.5.2 Yaroro Life Hotfix

This update makes moving the companion between windows and the desktop easier, then builds care and timer features on that more reliable interaction model.

## Dragging and landing

- Chooses the intended landing surface continuously while the companion is being dragged.
- Shows a green landing indicator for a program window and a blue indicator for the desktop.
- Keeps the previewed surface on release instead of recalculating a different nearest surface.
- Excludes the previous supporting window after the companion is dragged below its detach threshold.
- Cancels a drag with `Esc` and returns to the original position.
- Preserves the v0.4.4 landing-operation guard when the companion is grabbed repeatedly.

## Yaroro animation

- Uses dedicated tail-propeller and fall/landing illustrations so each reaction remains readable at desktop-pet size.
- Keeps all three final assets on the established transparent 418×418 canvas.
- Uses a tail-propeller effect while Yaroro is being carried.
- Uses a dedicated fast-fall pose and a faster Yaroro fall step.
- Shows a playful X-eyed, tongue-out stunned frame for 0.9 seconds after a long fall.
- Adds all three actions as optional custom-image slots with safe Standard-edition fallbacks.

## Full-screen behavior

- Changes the default full-screen behavior from hiding to quietly waiting at the bottom-right corner.
- Stops movement, dialogue bubbles, and automatic animation changes while waiting.
- Keeps direct dragging available and restores the previous surface after full-screen mode ends.

## Care and daily behavior

- Displays hunger, cleanliness, happiness, fatigue, affection, and the derived mood.
- Adds pet, clean, sleep, and wake interactions alongside feeding and play.
- Applies elapsed time independently of rendering and caps offline progress at 12 hours.
- Sleeps after five minutes without input and gives a cooldown-protected welcome when the user returns.
- Slows movement gently when hungry or tired; the character never dies or disappears.

## Timers and dialogue

- Adds 5/10-minute general timers, 25/50-minute focus timers, a 5-minute rest timer, and custom timers.
- Persists the active timer and shows remaining time in the character and tray menus.
- Allows timer completion messages even while other behavior is quiet.
- Adds optional hunger, fatigue, happiness, and local-time-range conditions to each dialogue.

## Compatibility

- Existing v0.4.x settings, care values, user images, and dialogue files remain readable.
- New user-image slots and timer data use safe defaults when absent.
- Standard and Yaroro editions continue to use separate data directories and installers.
