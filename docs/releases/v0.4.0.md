# Pixel Companion v0.4.0

This release separates the Standard and `for Yaroro` editions and adds a lightweight dialogue editor directly to the pet's right-click menu.

## Two independent editions

- `PixelCompanion-Installer.exe` installs the Standard edition with the default cat.
- `PixelCompanion-Yaroro-Installer.exe` installs the separate for Yaroro edition.
- The editions use different executable names, installation directories, startup entries, user-data directories, and update assets.
- Both editions can be installed on the same Windows computer without sharing settings.
- Existing Yaroro data is copied once from the legacy data directory when the separated edition starts for the first time.

## In-app dialogue editor

- Right-click the character and choose **Edit dialogues...**.
- Edit Korean and English dialogue for click, feed, play, and sleep reactions.
- Add and remove lines, set output probability, minimum affection, and cooldown, and preview the result in the character's speech bubble.
- Saved dialogue takes effect immediately.
- Dialogue JSON uses atomic replacement and backup recovery.
- `{time}` expands using the current localized time. Unsupported variables remain visible instead of causing an error.

## Verification

- Standard and for Yaroro builds compile independently.
- Core tests validate both bundled character packs, dialogue persistence and recovery, localization parity, update assets, and version consistency.
- Both Windows installers pass silent install, executable version, uninstall, and payload-isolation smoke tests.
