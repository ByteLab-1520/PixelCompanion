# Promotional media

- `character-settings.png` is a capture of the real v0.2.1 advanced settings application. It was launched with isolated demonstration data, so no maintainer user settings are shown.
- `desktop-pet-walk.gif` is a promotional animation composed from the bundled CC0 character asset. It illustrates the desktop walking experience and is not a recording of a user's desktop.
- `pixel-companion-hero.png` combines the real settings capture and bundled character with a generated promotional background.
- `yaroro-demo-v0.4.2.mp4` is an unedited 34-second, silent 720p screen recording of the real Yaroro edition on the maintainer's black second-monitor desktop. It demonstrates feeding, sleeping, greeting, mouse dragging, and landing on the corner of a window.
- `yaroro-demo-v0.4.2.gif` is a 960×540, 15 FPS looping conversion of the same recording for easy embedding.
- `yaroro-demo-v0.4.2-poster.png` is the window-corner landing frame extracted from that recording.
- `yaroro-character-settings-v0.4.4.png` is a direct capture of the v0.4.4 Yaroro advanced settings window using isolated demonstration data. It shows every bundled movement, eating, and sleeping image used as a fallback before the user selects a custom image.

The application UI and character are kept unmodified in the screenshots. The generated background is used only in repository promotional media; Pixel Companion itself does not include or call a generative-AI service.
